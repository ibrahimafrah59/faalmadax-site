# Faal Madax Primary and Secondary School website

The website for www.faalmadax.com, a school for orphans in Mogadishu, Somalia.

- `index.html` is the whole site (Home, Our Team and Support Us pages).
- `media/` holds the photos, videos and the 2023 and 2024 supporter reports.

It is a plain static site, so Vercel or Netlify can host it for free with no build settings.
